# Checklist ทดสอบบนมือถือจริง (ปิดงานวันที่ 8)

ทำทีละข้อ ติ๊กเมื่อผ่าน ถ้าไม่ผ่านให้จดอาการ (ข้อความที่เห็น/ภาพหน้าจอ) แล้วแจ้งกลับ
**ก่อนเริ่ม:** รัน `docker compose up -d --build frontend` ให้เวอร์ชันล่าสุดอยู่บน tunnel แล้วเปิด `bash scripts/demo-check.sh` ให้ผ่านทุกข้อ ·
อย่ารัน `test-all.sh` ระหว่างทดสอบ (recreate nodered ทำให้ข้อความเตือนจริงขาดช่วง)

## 0. iPhone ที่เคยค้างหน้าเก่า (C0 — ทำก่อนข้ออื่น)
- [ ] ลบไอคอนยาตรงเก่าออกจากหน้าจอโฮม → เปิด Safari เข้าลิงก์ → กด **Visit Site** → เพิ่มลงหน้าจอโฮมใหม่ → เปิดจากไอคอน
- [ ] เมนูล่างเป็นเวอร์ชันล่าสุด ("สรุป" ไม่ใช่ "ภาพรวม") และหน้าวันนี้โหลดตารางยาได้
- [ ] (จำลองคุกกี้หมดอายุ) เปิดเมนู Safari → ตั้งค่า → ล้างข้อมูลเว็บไซต์ของโดเมน ngrok แล้วเปิดแอปจากหน้าจอโฮมอีกครั้ง → เห็นแถบเหลือง **"การเชื่อมต่อหมดอายุ แตะเพื่อเชื่อมต่อใหม่"** (ไม่ใช่แค่ "เกิดข้อผิดพลาด")
- [ ] แตะแถบ → เห็นหน้า Visit Site → กดแล้วกลับมาที่หน้าวันนี้ แถบหายไป

## 1. Android — ติดตั้ง / shortcuts
- [ ] เปิดลิงก์ใน Chrome → เห็นการ์ด "ติดตั้งยาตรงไว้บนหน้าจอ" (หน้าวันนี้หรือตั้งค่า) → แตะ "ติดตั้งแอป" → ไอคอนหน้าน้องยาตรงบนหน้าจอโฮม (ไม่ถูกตัดขอบ)
- [ ] เปิดจากไอคอน = เต็มจอไม่มีแถบเบราว์เซอร์ ; พื้นหน้าจอเปิดแอปเป็นมิ้นต์อ่อน
- [ ] กดไอคอนค้าง → เห็น shortcut "ยาวันนี้" และ "สแกนซองยา" แล้วเปิดหน้าที่ถูกต้อง
- [ ] ติดตั้งแล้ว ไม่เห็นการ์ดชวนติดตั้งอีก

## 2. iPhone — เพิ่มหน้าจอโฮม + แจ้งเตือน
- [ ] เปิดใน Safari (ยังไม่เพิ่ม) → เห็นการ์ดสอนแชร์ → เพิ่มไปยังหน้าจอโฮม ตามขั้นตอนในการ์ด
- [ ] เปิดจากไอคอน → ตั้งค่า → "แจ้งเตือนบนเครื่องนี้" → เปิด → อนุญาต → ปุ่มทดลองส่งแล้วเห็นแจ้งเตือน (iOS 16.4 ขึ้นไป)
- [ ] แตะแจ้งเตือน → เปิดหน้าวันนี้ (iPhone ไม่แสดงปุ่ม "กินแล้ว" บนแจ้งเตือน)

## 3. โหมดเครื่องบิน (ออฟไลน์)
- [ ] เปิดหน้าวันนี้และสรุป 7 วันตอนมีเน็ต 1 ครั้ง → เปิดโหมดเครื่องบิน → เปิดแอปใหม่
- [ ] เห็นแถบ "ออฟไลน์อยู่ · ข้อมูลล่าสุดเมื่อ HH:MM น." ; หน้าวันนี้และสรุปยังแสดงข้อมูลล่าสุด
- [ ] ปุ่ม "กินแล้ว" กดไม่ได้ และมีข้อความ "ต่ออินเทอร์เน็ตก่อนนะคะ"
- [ ] ปิดโหมดเครื่องบิน → แถบหาย และข้อมูลรีเฟรชเอง (ไม่ต้องกดอะไร)
- [ ] ออกจากระบบ แล้วเข้าด้วยบัญชีอื่น → ไม่เห็นข้อมูลของบัญชีแรก (แม้อยู่โหมดเครื่องบิน)

## 4. เสียงอ่าน (🔊) — iPhone และ Android
- [ ] หน้าวันนี้: ปุ่ม "ฟังยาที่ต้องกินวันนี้" ออกเสียงภาษาไทยชัด (เวลา "หกโมงเช้า / บ่ายโมง" ไม่ใช่เลขดิบ) ; กดซ้ำ = หยุด
- [ ] ยาที่ชื่อตัวพิมพ์ใหญ่ เช่น METFORMIN อ่านเป็นคำ ไม่สะกดทีละตัว (C5) ; ชื่อบนจอยังเป็นตัวพิมพ์ใหญ่ตามเดิม
- [ ] ตั้งค่า → เสียงอ่าน: ปรับความเร็ว ช้า/ปกติ แล้วกด "ทดลองฟัง"
- [ ] ฟอร์มยา: ใส่ "ชื่อที่ให้อ่านออกเสียง" แล้วกดฟัง → อ่านตามที่ใส่ ; หน้าสรุป "อ่านสรุปให้ฟัง"
- [ ] เครื่องที่ไม่มีเสียงไทย: ไม่เห็นปุ่ม 🔊 เลย และการ์ดในตั้งค่าบอกวิธีเพิ่มเสียง

## 5. LINE "สรุป"
- [ ] บัญชีผู้ป่วย: พิมพ์ "สรุป" → การ์ดอัตรา 7 วัน แถว ✓/✕/–/● และปุ่ม "ดูรายละเอียด"
- [ ] บัญชีผู้ดูแล: พิมพ์ "สรุป" → ของผู้ป่วยที่ดูแล **ไม่มีชื่อยา**
- [ ] บัญชีที่เป็นทั้งสองบทบาท: ได้ 2 ข้อความ (ของตัวเองก่อน)

## 6. อัปเดตเวอร์ชัน
- [ ] (ผู้พัฒนา build ใหม่ + `docker compose up -d --build frontend`) เปิดแอปที่ติดตั้งไว้ → รอสักครู่ → เห็น snackbar **"มีเวอร์ชันใหม่ แตะเพื่ออัปเดต"** (ปุ่มกดง่าย) → แตะแล้วแอปโหลดใหม่เป็นเวอร์ชันล่าสุด
- [ ] ยังไม่แตะ = แอปไม่โหลดใหม่เอง

## 7. Web Push เดิมต้องยังใช้ได้ (ห้ามพัง)
- [ ] Android: แจ้งเตือนเวลากินยามีปุ่ม "✓ กินแล้ว" → แตะ → บันทึกให้ (ผ่าน `/today#take=…`)
- [ ] แตะตัวแจ้งเตือน (ไม่ใช่ปุ่ม) → เปิดหน้าวันนี้
