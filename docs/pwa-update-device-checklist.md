# ชุด 8 — อัปเดต PWA (fix/pwa-update) บน S23 FE และ iPhone

ทดสอบเมื่อ: S23 FE พร้อมก่อน, iPhone วันถัดไป · **ไม่ต้องออกจากระบบ ไม่ต้องถอนการติดตั้ง PWA** (PWA ของบัญชี "การ์ตูน" ถือ Web Push — ห้ามออกจากระบบ/ถอนการติดตั้ง)

## ผลทดสอบ
- **S23 FE (Samsung Galaxy S23 FE, SM-S711B): ชุด 8 ผ่านแล้ว** (คาเด็ทยืนยัน)
- **iPhone — 18 ต.ค. 2569 (2026-10-18):** iPhone 16 · iOS 18.7 · viewport 402px · DPR 3 · แอปจากหน้าจอโฮม (บัญชีผู้ทดสอบ) + Safari แท็บส่วนตัว
  - **ผ่าน:** 8-0b, 8-1, 8-2, 8-3, 8-4, 8-5, 8-6, 8-7
  - **ข้ามตามแผน:** ชุด C (8-8 ถึง 8-11) — iPhone ไม่มีวิธีจำลองการโหลดล้มเหลวโดยไม่แก้เซิร์ฟเวอร์ (ผ่านบน S23 แล้ว)
  - ไม่มีข้อที่ต้องออกจากระบบ/ถอนการติดตั้ง PWA

## กฎการ deploy (ทุกครั้งที่ rebuild ต้องถามคาเด็ทก่อน)
- rebuild เฉพาะ frontend: `docker compose up -d --build --no-deps frontend` (ไม่แตะ nodered/db)
- **ห้าม rebuild ในช่วง ± 10 นาทีของเวลามื้อของบัญชีทดสอบ** (ดูเวลามื้อในแอป ตั้งค่า → เวลามื้อ ก่อนทุกครั้ง) — เตือน LINE/Web Push ทำงานบน nodered ซึ่งไม่ถูก recreate แต่ถ้าคาเด็ทกำลังกดยืนยันกินยาจะเจอหน้าเว็บกระตุกช่วง container เปลี่ยน
- ทุกครั้งที่ rebuild ซอร์สเดิม (ไม่แก้โค้ด) `ngsw.json` ได้ `timestamp` ใหม่ → service worker นับเป็น "เวอร์ชันใหม่" (ไฟล์ chunk เดิมถูกใช้ซ้ำ) จึงใช้จำลองการออกเวอร์ชันใหม่ได้โดยไม่แก้โค้ด
- เวลาที่อธิบายด้านล่าง "เว้น 5 นาที" = ต้องปล่อยแอปอยู่เบื้องหลังอย่างน้อย 5 นาที (นับจากการเช็กครั้งก่อน/เปิดแอป) ก่อนกลับมาเปิด
