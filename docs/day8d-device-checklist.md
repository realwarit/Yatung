# เช็กลิสต์ทดสอบบนมือถือจริง — 8D (ดีไซน์ใหม่)

ทดสอบบนเครื่องจริงทั้ง iPhone (Safari และแอปจากหน้าจอโฮม) และ Android (Chrome) หลังรัน `docker compose up -d --build frontend`

## คีย์บอร์ดกับปุ่มยืนยัน (Login / Register)
- [ ] Android: แตะช่องอีเมล → คีย์บอร์ดเปิด → ปุ่ม "เข้าสู่ระบบ" ยังเห็นอยู่ (หน้าหดตามคีย์บอร์ด `interactive-widget=resizes-content`)
- [ ] Android: แถบเมนูล่างไม่ลอยขึ้นมาอยู่บนคีย์บอร์ด ในหน้าฟอร์มยา (`kb-open` ซ่อนแถบ) และกลับมาเมื่อปิดคีย์บอร์ด
- [ ] iPhone: แตะช่องรหัสผ่าน → ปุ่มยืนยันเลื่อนขึ้นมาให้เห็น (scrollIntoView หลัง ~300ms)
- [ ] iPhone: แตะช่องกรอกทุกช่อง หน้าไม่ซูมเอง (ช่องกรอก ≥ 16px)
- [ ] ปิดคีย์บอร์ดแล้วแถบเมนูล่างกลับมาครบ ทั้ง Android และ iPhone

## ขนาดตัวอักษร
- [ ] ผู้ใช้ที่เคยเลือกขนาดไว้ก่อน 8D เห็นขนาดเดิมโดยประมาณ (เดิม ก = 18px → ตอนนี้ ก+ = 18px)
- [ ] ผู้ที่ไม่เคยเลือก เห็นแถบ "ปรับขนาดตัวอักษรให้ใหญ่ขึ้นได้ที่ ตั้งค่า" ครั้งเดียว กดปิดแล้วไม่โผล่อีก
