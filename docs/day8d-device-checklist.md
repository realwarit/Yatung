# เช็กลิสต์ทดสอบบนมือถือจริง — 8D (ดีไซน์ใหม่)

ทดสอบบนเครื่องจริงทั้ง iPhone (Safari และแอปจากหน้าจอโฮม) และ Android (Chrome) หลังรัน `docker compose up -d --build frontend`

## คีย์บอร์ดกับปุ่มยืนยัน (Login / Register)
- [ ] Android: แตะช่องอีเมล → คีย์บอร์ดเปิด → ปุ่ม "เข้าสู่ระบบ" ยังเห็นอยู่ (หน้าหดตามคีย์บอร์ด `interactive-widget=resizes-content`)
- [ ] Android: แถบเมนูล่างไม่ลอยขึ้นมาอยู่บนคีย์บอร์ด ในหน้าฟอร์มยา (`kb-open` ซ่อนแถบ) และกลับมาเมื่อปิดคีย์บอร์ด
- [ ] iPhone: แตะช่องรหัสผ่าน → ปุ่มยืนยันเลื่อนขึ้นมาให้เห็น (scrollIntoView หลัง ~300ms)
- [ ] iPhone: แตะช่องกรอกทุกช่อง หน้าไม่ซูมเอง (ช่องกรอก ≥ 16px)
- [ ] ปิดคีย์บอร์ดแล้วแถบเมนูล่างกลับมาครบ ทั้ง Android และ iPhone

## ขนาดตัวอักษร
- [ ] ผู้ใช้ที่เคยเลือกขนาดไว้ก่อน 8D เห็นขนาดเดิมโดยประมาณ (เดิม ก = 18px → ตอนนี้ ก+ = 18px)
- [ ] ผู้ที่ไม่เคยเลือก เห็นแถบ "ปรับขนาดตัวอักษรให้ใหญ่ขึ้นได้ที่ ตั้งค่า" ครั้งเดียว กดปิดแล้วไม่โผล่อีก

# D2 — หน้าวันนี้ / Login / Register / สแกน / Review

build ที่ใช้ทดสอบ: หลัง `docker compose up -d --build frontend` (+ recreate nodered เพื่อโหลด endpoint `POST /api/doses/take-many`) · ทดสอบ iPhone (Safari + แอปจากหน้าจอโฮม) และ Android (Chrome) อย่างละเครื่อง ที่ขนาดตัวอักษร ก และ ก+

## หน้าวันนี้
- [ ] จอแรกเห็นครบ: ทักทาย + วันที่ · การ์ดความคืบหน้า · ปุ่ม "กินแล้ว" ตัวแรกของมื้อที่ถึงเวลา/เลยเวลา (ไม่ต้องเลื่อน) ทั้ง ก และ ก+
- [ ] **ตัวนับ "อีก n นาที"** (มื้อถัดไปที่พับไว้): เทียบกับนาฬิกาเครื่อง — เช่น เวลา 21:13 มื้อ 21:18 ต้องเป็น "อีก 5 นาที" ; รอ 1 นาที ต้องลดลงเอง ; ลองทั้งออนไลน์และเปิดโหมดเครื่องบิน (ออฟไลน์) แล้วเปิดแอปจากหน้าจอโฮม — ค่าต้องตรงนาฬิกา ไม่ค้างค่าเดิม ; ถึงเวลาแล้วต้องเปลี่ยนเป็นมื้อที่เปิด "ถึงเวลาแล้ว" เอง
- [ ] แตะแถวมื้อที่พับ (มื้อถัดไป/กินครบแล้ว) แล้วกางออกได้ ; มื้อถัดไปที่กางออก **ไม่มี**ปุ่ม "กินครบมื้อนี้" แต่กด "กินแล้ว" ทีละตัวได้เหมือนเดิม
- [ ] "กินครบมื้อนี้" (มื้อที่เปิดและมียาที่ยังไม่กิน ≥ 2 ตัว): กดแล้วทุกตัวเป็น "กินแล้ว" พร้อมกัน, ขึ้น "บันทึก n รายการแล้วค่ะ", ยกเลิกทีละตัวได้ภายใน 10 นาที, ยอดยาคงเหลือลดถูก (ดูที่หน้ายาของฉัน)
- [ ] ปุ่ม 🔊 "ฟัง" (การ์ดความคืบหน้า) และไอคอน 🔊 ที่หัวมื้อ: กดแล้วอ่านทันที (ไม่ต้องกดสองครั้ง) ; ไม่อ่านเอง (รวมตอนเปิดจากแจ้งเตือน Web Push `/today#take=…`)
- [ ] ออฟไลน์: แถบเทา-น้ำเงินด้านบนแถบเดียว · ปุ่มกินแล้วดูจาง · **ไม่มีข้อความใต้ทุกแถว** · แตะปุ่มที่กดไม่ได้แล้วขึ้น "ต่ออินเทอร์เน็ตก่อนนะคะ" ครั้งเดียว (แตะซ้ำไม่ขึ้นอีกจนกว่าจะกลับมาออนไลน์แล้วหลุดอีก)
- [ ] กินครบทั้งวัน: เห็นน้องยาตรงตัวใหญ่ท่าดีใจ + "วันนี้กินครบแล้ว เก่งมากเลยค่ะ"
- [ ] แถว "7 วันล่าสุด กินครบ n% ›" ท้ายหน้าแตะแล้วไปหน้าสรุป
- [ ] ปุ่มสแกนกลางแถบเมนู (ยื่นขึ้น 20px) ไม่บังปุ่ม "กินแล้ว"/แถวท้ายหน้า

## Login / Register
- [ ] ทุกช่อง + ปุ่มยืนยันเห็นในจอแรก (Register ที่ ก+ บนจอเล็กเช่น iPhone SE/360×640 ก็ต้องเห็นปุ่ม "สมัครสมาชิก") — บรรทัดรอง "สร้างบัญชี…" ซ่อนเองบนจอเตี้ย (< 700px) เป็นการออกแบบ
- [ ] **แถบด้านบน** (เช่น ออฟไลน์) ที่ Login/Register: แถบแถวเดียวไม่บังโลโก้/ตัวเลือก ก ก+ ก++
- [ ] น้องยาตรง M (56px): แตะช่องอีเมล = เหลือบมอง · แตะช่องรหัสผ่าน = ปิดตา · กด "แสดงรหัส" = แง้มนิ้ว · ใส่ผิด = เป็นห่วง · กำลังส่ง = คิด — ดูว่าท่าอ่านออกจริงบนจอเครื่อง (ภาพจำลองอยู่ที่ `docs/screenshots/day8d/index.html`)
- [ ] ตัววัดความแข็งแรงรหัสผ่านอยู่แถวเดียวกับป้าย "รหัสผ่าน" (ขวา) ไม่ทำให้ฟอร์มกระโดดตอนเริ่มพิมพ์
- [ ] **คีย์บอร์ด (kb-open)**: Android + iPhone — แตะช่อง "ข้อความ" (อีเมล รหัสผ่าน ชื่อยา ข้อความที่พิมพ์เอง) → แถบเมนูล่างซ่อน ; แตะ select/ปุ่ม/ช่องเลือกเวลา → แถบเมนูไม่ซ่อน ; ย้ายระหว่างช่องไม่กะพริบ ; ปุ่มติดล่างของหน้า (บันทึกยา, บันทึกผลสแกน) ยังเห็นเหนือคีย์บอร์ดเสมอ ; iPad/จอ ≥ 1024px ไม่มีผลอะไร

## สแกน
- [ ] จอแรกเห็นครบ: แถบ AI (น้องยาตรงตัวเล็ก) · คำแนะนำ 3 ข้อในกรอบ · ปุ่ม "ถ่ายรูปซองยา" · ปุ่ม "เลือกรูปจากเครื่อง" — ทั้ง ก และ ก+, และตอนมีแถบด้านบน 1 แถบ
- [ ] ไม่มีอะไรเลื่อนแนวนอนในหน้า ; ไม่มีแถบเหลืองคลุมปุ่ม "เลือกรูปจากเครื่อง" ตอนมีแจ้งเวอร์ชันใหม่ (แจ้งเป็นแถบด้านบนแล้ว)
- [ ] ถ่ายรูปด้วยกล้อง (Android + iPhone) แล้วไปหน้าตรวจ ; ระหว่างอ่านขึ้น "กำลังอ่านซองยาอยู่นะคะ..." พร้อมน้องยาตรงตัวเล็ก ; ปุ่ม "ยกเลิก" ใช้ได้ ; ปุ่ม ← "เพิ่มยาใหม่" กลับหน้าวันนี้ (ถามยืนยันถ้ามีรูปค้าง)
- [ ] โหมด "พิมพ์เอง": พิมพ์ได้ ไม่ซูมเอง (iPhone) ; chip คำที่ใช้บ่อยเติมที่ตำแหน่ง cursor

## Review (ตรวจข้อมูลยา)
- [ ] แถบบนสุด: เหลือง (มีจุดต้องตรวจ) / ฟ้า (ไม่มี) + จำนวนช่องที่ควรตรวจ ลดลงเมื่อตรวจ ; "ส่วนที่น้องไม่แน่ใจ" กางอยู่ในแถบเดียวกัน (ไม่มีกล่องเหลืองซ้อน)
- [ ] ช่องที่ติด flag + ช่องที่ว่าง **กางเสมอ** ; ช่องที่ไม่ติด flag พับเป็นบรรทัดสรุปที่มี **ค่าจริงทุกค่า** (เช่น "1 เม็ด · หลังอาหาร · เช้า เย็น · 60 เม็ด") ; "แก้ไข" กางทุกช่องในที่เดิม ; ชื่อยา+ความแรงกางเสมอ
- [ ] แถบปุ่มติดล่าง (ทิ้ง / บันทึก N รายการ) เห็นตลอดแม้ฟอร์มยาว และเห็นเหนือคีย์บอร์ดตอนแก้ช่อง ; ปุ่มบันทึกปิดอยู่ต้องมีเหตุผลบรรทัดเดียว + "ไปจุดถัดไป"
- [ ] บันทึกสำเร็จ: น้องยาตรงตัวใหญ่ท่าดีใจ + รายการที่บันทึก

# ผลทดสอบเครื่องจริง — Samsung Galaxy S23 FE (ชุด 4: ขนาดตัวอักษร ก++ หน้าสแกน)

| แถว | ขั้นตอน | ผล | หมายเหตุ |
|---|---|---|---|
| 4-1 ถึง 4-4 | (ตามชุด 4 ใน `docs/day8-device-checklist.md`) | ผ่าน | Samsung Galaxy S23 FE |
| **4-5** | ตั้งขนาด ก++ → หน้าสแกน → ถ่ายรูปแล้ว (ภาพ 1200×1600) → ดู action bar ใต้ภาพ | **ผ่าน (14 ต.ค.)** | Samsung Galaxy S23 FE (แก้ใน 3e9a056, 07896f0); ก่อนแก้: ปุ่ม "ให้น้องยาตรงอ่านซองยา" ยื่นเลยขอบขวาของการ์ดขาว ~28px |

**ต้นเหตุ:** แถว action bar เป็น grid คอลัมน์ `auto` จึงกว้างตามป้ายปุ่มที่ไม่ตัดบรรทัด (ปุ่มกว้างเกินการ์ด) ; กติกาป้ายสั้นเดิมใช้เฉพาะปุ่มโหมดพิมพ์เอง และตัดสินด้วย container query ตายตัว ; เกณฑ์ตรวจเดิมไม่ได้วัดสถานะ "มีภาพแล้ว" และไม่วัดลูกล้นการ์ด
**แก้:** คอลัมน์ `minmax(0, 1fr)` + ปุ่มกันล้นที่ต้นเหตุ + directive `fitLabel` (วัดจริง: ป้ายเต็ม → ป้ายสั้น "อ่านซองยา" → ซ่อนไอคอน → ลดตัวอักษรทีละ 1px ไม่ต่ำกว่า 16px)

## ทดสอบซ้ำบน Samsung Galaxy S23 FE (หลัง build ใหม่)
- [ ] ตั้งขนาด ก++ → หน้าสแกน → ถ่ายรูป → ปุ่ม "อ่านซองยา" (หรือป้ายเต็มถ้าที่พอ) อยู่ในกรอบการ์ดขาว ขอบซ้าย-ขวาเท่ากับกรอบภาพ ไม่มีส่วนยื่น
- [ ] ลองขยายตัวอักษรของระบบ (ตั้งค่า Android → จอภาพ → ขนาดตัวอักษร) แล้วเปิดหน้าสแกนอีกครั้ง ปุ่มยังอยู่ในการ์ด บรรทัดเดียว
- [ ] ตั้งค่า → "ข้อมูลสำหรับผู้พัฒนา" (เฉพาะโหมดเดโม) → การ์ด "ข้อมูลจอ": จดค่า innerWidth / visualViewport / devicePixelRatio / ขนาดตัวอักษรหลัก / ตัวอักษรของปุ่มหลัก ส่งกลับมาเทียบกับภาพจำลอง (ข้อมูลแสดงบนจอเท่านั้น)
