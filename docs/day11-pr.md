## สรุปงาน (วันที่ 11)

ยาตรงเป็นแอปเตือนกินยาสำหรับ **ทุกคนทุกวัย** (วิตามิน ยาประจำตัว ยาชั่วคราว) ไม่ใช่เฉพาะผู้ป่วย — PR นี้เอาคำว่า "ผู้ป่วย / ผู้ดูแล / ญาติ" ออกจากข้อความที่ผู้ใช้เห็นทั้งหมด และเปลี่ยนชื่อฟีเจอร์แจ้งญาติเป็น **"คนที่ห่วงใย"** พร้อมเก็บงานค้าง 3 ข้อ

- **ช่วง A (frontend):** หน้าตั้งค่า / คนที่ห่วงใย / welcome / auth / หน้าสรุป / manifest / ป้ายช่องทาง ; หน้า Review แสดง token ปิดชื่อ `[ชื่อผู้ป่วย]` เป็น `[ชื่อ]` เฉพาะตอนแสดงผล
- **ช่วง B (LINE / API):** ข้อความ LINE ทุกแบบ (reply, Flex, altText, ตัวอย่าง `#ตัวอย่าง`), error ของ API คนที่ห่วงใย/ปุ่มเดโม ; Web Push ไม่มีคำต้องห้ามอยู่แล้ว ไม่ต้องแก้
- **งานค้าง:** `start_url`, README hash รหัส Node-RED, `remind-now` ส่ง Web Push ตาม cron
- **แก้ UI ที่พบระหว่างทาง:** แถวรายการตั้งค่า (ลูกศร `>` ไม่ตกบรรทัด ที่ 320px) · บรรทัด "บันทึกผ่าน …" หน้าสรุป · ป้าย "แจ้งเตือนบนเครื่องนี้" ไม่ให้ "นี้" ตกบรรทัดเดี่ยว
- **เทสกันคำหลุด:** `node-red/test/no-forbidden-words.test.js` + `frontend/tools/wording-bundle-check.mjs` (ถอด `\uXXXX`, มีตัวควบคุมบวก, ข้อยกเว้นเดียวคือสตริง `[ชื่อผู้ป่วย]` ใน `review.model.ts`)
- **ไม่เปลี่ยน:** ชื่อตาราง/คอลัมน์ DB (`caregivers` ฯลฯ), endpoint (`/api/caregivers`), ชื่อไฟล์/คลาส, ชื่อ node/tab ใน Node-RED, พรอมต์/schema Gemini, `docs/day*-plan.md` เก่า

## งานค้าง 8–10

- **start_url:** manifest เป็น `/` อยู่แล้ว (ตั้งแต่ welcome) ที่ตกคือสคริปต์ตรวจ `demo-check.sh` / `test-day8.sh` ที่ยังคาด `/today` → แก้สคริปต์ให้คาด `/` ; **ไม่แตะ `id` และ `scope`** (กัน WebAPK บน S23 FE และ Web Push หลุด)
- **README hash รหัส Node-RED:** ใช้ `docker compose exec -it nodered node -e "…bcryptjs.hashSync…"` อ่านรหัสจาก stdin (คำถามอยู่ stderr) แทน `docker compose run … node-red admin hash-pw` ที่เปิด Node-RED ตัวที่ 2 ; ทดสอบด้วยรหัสสุ่มทั้ง Git Bash และ PowerShell (ได้ hash 60 ตัว, `compareSync` = true)
- **`POST /api/demo/remind-now`:** `remindNow` / `remindDemoUser` รับ `push` แล้วเลือกช่องทางแบบ cron (LINE / Web Push / ทั้งสอง / โควตา LINE เต็ม → Web Push) · ผู้ใช้ที่ไม่เชื่อม LINE แต่มีเครื่องกดได้ · ข้อความตอบตามช่องทางจริง · response เพิ่ม `push_sent` · แก้ `flows.json` 2 node (`ln_demo_fn`, `ln_dmi_fn`) ให้ส่ง `pushService` · เทสใหม่ 7 ตัว (ใช้ fake-push ทั้งหมด ไม่ส่งจริง)
